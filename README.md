# Anuj Bhatt — Systems Architect Portfolio

A static, GitHub Pages-ready portfolio built around the **Systems // Architect** design direction: enterprise futurism, architecture-led storytelling, restrained motion, responsive layouts, and SEO fundamentals.

## Structure

- `index.html` — homepage
- `work/` — case studies
- `experience.html` — complete career timeline
- `architecture.html` — architecture principles
- `about.html` — profile and credentials
- `insights/` — future technical writing hub
- `contact.html` — contact details
- `styles.css` — design system
- `app.js` — progressive-enhancement interactions
- `assets/Anuj-Bhatt-Resume.pdf` — current résumé supplied for this build

## Deployment

This is intentionally dependency-free and can be deployed directly to GitHub Pages from the repository root.
